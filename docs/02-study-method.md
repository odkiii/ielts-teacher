# 02. Методика подготовки (52 недели + буфер)

Старт: **понедельник 2 ноября 2026** (неделя 1). Каждая фаза описана по неделям, чтобы план не зависел от календаря.

## 0. Интейк и диагностика (недели 1–2)

### Вопросы (интейк)
1. Модуль: **Academic** или **General Training**? Зачем (вуз/виза/работа)? Требуемый общий балл и минимум по секциям?
2. Дата теста (или «не определена») и страна сдачи. Доступность Writing on Paper?
3. Часов в неделю и распределение (будни/выходные). Лучшее время дня.
4. Самооценка 0–10 по L/R/W/S и по грамматике, словарному запасу, произношению.
5. Последний официальный/пробный результат (если был) с датой.
6. Что тяжелее всего: тайм-менеджмент? лексика? грамматика? страх говорить? орфография?
7. Среда: сколько времени в день уже слушаешь/читаешь английский? Есть ли с кем говорить?
8. Устройство, микрофон, наушники; предпочтения (видео/текст/аудио).
9. Что уже пробовал и что не зашло?

### Диагностика (по одному заходу, без подсказок, в условиях теста)
- **Listening + Reading:** по одному полному официальному бесплатному практическому тесту нужного модуля (ссылки в `resources.yaml`, тег `official_practice`). Баллы → band по официальной конверсии *именно этого* теста.
- **Writing:** Task 1 (20 мин) + Task 2 (40 мин), набирать на клавиатуре.
- **Speaking:** записать Part 1 (4–5 мин), Part 2 (2 мин речь + 1 мин подготовка), Part 3 (4–5 мин) по открытому списку вопросов.
- Результат: стартовый `skill_state` + **теги слабостей** (из кодов ниже) + первичная оценка Writing/Speaking с калибровкой по протоколу ниже.

> У вас с девушкой профили **разные**: диагностика проходится независимо, планы не копируются.

## 3. Внутри каждого навыка

### Listening
- P1: короткие аудио с транскриптом (BBC 6 Minute English, ELLLO, Breaking News English) → слушание без текста → со скриптом → разметка непонятых слов.
- Приём: **дикtant** 3–5 предложений в день (лучший способ найти пробелы).
- P2–P3: университетские лекции, TED, официальные тесты Section 3–4; тренировка map/plan, multiple choice, distractors.
- Shadowing: 3–5 минут одного отрезка, 3 прогона (с текстом → без → одновременно), запись себя.
- Орфография и числа: тренировка отдельно (самая частая «потеря» баллов на Listening).

### Reading
- P1: графированные тексты B1–B2 + таймер без давления; находить ключевые слова/перефразы.
- P2: по типам: T/F/NG, matching headings, matching information, completion, MCQ. Для каждого типа — 3–5 тренировок + разбор логики ошибок.
- P3: полные тайминги (60 мин), стратегия «читать вопросы → искать → подтверждать».
- Academic: научно-популярные тексты (New Scientist-стиль, лонгриды); General Training — объявления, рабочие тексты, лонгрид.

### Writing
- P1: предложения → абзацы → простые эссе. Набор «рамок» Task 2: opinion, discussion, advantage/disadvantage, problem/solution, two-part.
- Task 1 (Academic): трендовые графики, таблицы, процессы, карты; GT: письма трёх тонов (formal/semi/informal).
- Цикл на каждое эссе: **план 5 мин → писать → самопроверка по чек-листу → оценка (протокол ниже) → переписать слабый абзац**. Переписывание ценнее новых эссе.
- Чек-лист Band 8 (из официальной разборки IDP): ответить на все части вопроса, не обобщать слишком широко, чёткая позиция, один абзац = одна идея с примером, разнообразные связки без «Firstly…» в начале каждой фразы, точная лексика и коллокации, избегать клише/заученных формул, разнообразная грамматика с большинством безошибочных предложений, пунктуация [S9].
- 1–2 раза в неделю, начиная с P2, — **редактирование чужого band-6 текста до band 7+** (развивает глаз на ошибки).

### Speaking
- P1: ответы 2–3 предложения на Part 1, работа над беглостью без пауз-заполнителей-паразитов, базовая интонация.
- P2: Part 2: схема «ситуация → детали → эмоция/оценка → вывод», 1–2 мин. Репертуар 20–25 универсальных тем-историй (человек, место, предмет, событие), которые адаптируются под карточки.
- P3: Part 3: «позиция → причина → пример → ограничение/контраргумент».
- **Пара-режим:** вы двое по очереди экзаменатор/кандидат по открытым карточкам; экзаменатор оценивает по 4 критериям (FC, LR, GRA, P).
- Записи всегда: слушай себя через день, фиксируй ошибки в журнал.

### Vocabulary / Grammar
- SRS ≤15–20 мин в день, **chunks с примером**, новые 8–12/день (подстройка по удержанию).
- P1: NGSL + Oxford 3000 пробелы; P2: AWL/NAWL + тематические коллокации (education, environment, technology, health, work, crime, media, city…); P3: AVL top + perifrazа.
- Активация: каждое новое слово → одно своё предложение + одно использование в Writing или Speaking в течение 3 дней. Слово, которое ты не использовал активно, — не выученное.
- Грамматика: целиться в самые частые ошибки из журнала (артикли, формы слов, согласование, времена, условные, относительные).

## 4. Журнал ошибок (теги)

```
L-SPELL  L-PLURAL  L-NUM  L-DISTR  L-MAP  L-LIMIT   (Listening)
R-TFNG   R-MH      R-MI   R-COMP   R-MCQ  R-TIME    (Reading)
W-TR     W-CC      W-LR   W-GRA    (+ подтеги: W-ART, W-WF word form, W-SVA, W-PUNCT, W-COLL, W-REP)
S-FC     S-LR      S-GRA  S-P      (Speaking)
```
Правило: любая ошибка → строка в журнале (фрагмент, правильный вариант, тег). Раз в неделю смотрим топ-3 тега и целенаправленно тренируем.

## 5. Протокол оценки Writing/Speaking через ИИ (калибровка)

1. Подготовь промпт: задача, текст, **публичные band descriptors** соответствующего Task, 2–3 якорных ответа с известными баллами.
2. Требуй: (а) диапазон по каждому критерию, (б) цитаты из текста, обосновывающие баллы, (в) 3 приоритетных исправления, (г) переписанный абзац на 1 уровень выше.
3. Оцени дважды в двух разных ИИ; если разрыв >0.5 → оценка «спорная», ориентируйся на нижний край.
4. Завышение — частый риск: в предпочтительном случае считай итоговый band **нижним** из диапазонов. [E]
5. Не используй оценку ИИ, чтобы «сравнить» с реальными результатами IELTS без калибровки; сверяй с мок-тестами, которые проверяются по ключам (L/R).

## 6. Метрики

- Доля выполненных дней (цель ≥85%).
- Часы по навыкам vs план.
- L/R: raw → band на моках каждые 4 недели.
- W/S: диапазон по критериям (медиана за 4 недели).
- Топ-3 тегов ошибок, динамика.
- Удержание SRS (цель ≥85–90%).
