# 04. Откуда контент (карточки, Reading, Writing)

**Честно о статусе проверки.** Это учебный контент проекта, а не копия чужих материалов.

## Карточки (`data/deck/*.txt` → `app/data/deck.json`, ~530 штук)
- **Отбор слов:** опора на открытые академические и частотные списки — Academic Word List (A. Coxhead, Victoria University of Wellington), общеупотребительные коллокации для Writing Task 2/Task 1/Speaking. Сайт AWL автор проекта при сборке не смог открыть для сверки, поэтому слова подобраны по памяти и **не сверены построчно** со списками. Добавь сверку в PR, если хочешь.
- **Переводы и примеры** написаны для проекта (оригинальный текст, не из словарей). Перед заучиванием сложных слов сверяй значение и коллокации в [Cambridge Dictionary](https://dictionary.cambridge.org/) или [Oxford Learner's Dictionaries](https://www.oxfordlearnersdictionaries.com/).
- Формат строки: `term|перевод|пример с [[формой слова]]|pos|домен`. Сборка: `npm run data`.

## Reading (`app/data/reading.json`)
5 учебных текстов (Academic-формат, 66 вопросов: matching headings, matching information, True/False/Not Given, completion). Тексты оригинальные; не из Cambridge/IDP/British Council. Типы заданий соответствуют официальному описанию формата (см. [IDP: Reading question types](https://ielts.idp.com/prepare/article-ielts-reading-question-types)). Пересчёт в band — приблизительный.

## Writing (`app/data/writing.json`)
20 вопросов Task 2, 8 заданий Task 1 (данные вымышленные), 6 писем GT. Темы отражают повторяющиеся кластеры 2024–2026 из отчётов кандидатов (образование, технологии и работа, окружающая среда, здоровье, город и транспорт, культура, преступность, СМИ). Настоящие вопросы IELTS не публикуются, поэтому это не оригинальные экзаменационные задания.

## Уровни карточек (CEFR) и типы

Каждая карточка имеет тип: слово, **коллокация** (`coll`), **фразовый глагол** (`phv`), **идиома** (`idiom`), **оборот/связка** (`hedge`).

**Уровни CEFR — только из официальных данных.** Вручную они не ставятся. Скрипт `scripts/official_levels.py` сопоставляет карточки со списками:

- [The Oxford 3000 / Oxford 5000 by CEFR level](https://www.oxfordlearnersdictionaries.com/about/wordlists/oxford3000-5000) (Oxford University Press) — уровни A1–C1 для слов и ряда выражений;
- [Academic Collocation List](https://www.pearsonpte.com/teachers/academic-collocation/) (Pearson, 2 469 академических коллокаций) — подтверждает, что коллокация входит в список (поле `acl`; уровней CEFR в нём нет).

Результат: `data/official_levels.json` (только пары «карточка → уровень, источник»; сами списки в репозиторий не включены). Карточки без совпадения **остаются без уровня** и подмешиваются на уровне ученика. Сейчас уровень подтверждён примерно у 40% карточек — в основном у отдельных слов; фразы, фразовые глаголы и идиомы в этих списках почти не представлены. Для них нужен English Vocabulary Profile (Cambridge): его сайт динамический и без выгрузки, поэтому уровни оттуда добавляются вручную (см. CONTRIBUTING).

**Как это используется.** Уровень ученика считается по среднему баллу (<5.5 → B1, <7 → B2, <8.5 → C1, иначе C2) или задаётся в Настройках. Новые карточки идут в порядке: на ступень выше уровня ученика → его уровень (и карточки без подтверждённого уровня) → на две ступени выше → ниже → слишком сложные.

**Практика после карточек.** Экран «Текст со словами»: 6 выученных выражений, ты пишешь текст, приложение проверяет, какие из них использованы, и готовит промпт для ИИ-проверки естественности.

Часть выражений вдохновлена открытыми разборами преподавателей IELTS (9.0 overall); примеры предложений написаны заново.

**Пересобрать:** `python3 scripts/official_levels.py <Oxford_3000.pdf> <Oxford_5000.pdf> <ACL.pdf> && python3 scripts/build_deck.py` (нужен `pdftotext`).
