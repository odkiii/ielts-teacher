# Как помочь проекту

## Добавить ресурс
1. Открой `data/resources_extra.yaml` (или `resources.yaml`) и скопируй существующую запись.
2. Поля: `id`, `name`, `url`, `type`, `skills`, `level`, `cost: free`, `ru_risk`, `status`, `notes`.
3. `status`: `verified_<дата>` только если ты сам открыл ресурс и он реально бесплатный; иначе `to_verify`.
4. Запусти `npm run data` и `npm test`, приложи изменения в PR.

## Правила
- Только **легальные бесплатные** ресурсы. Никаких пиратских книг, сливов платных курсов и файлов с нарушением авторских прав.
- Не копируй тексты из Cambridge/IDP/British Council и других защищённых источников. Фразы и примеры — только оригинальные.
- Не коммить персональные данные и экспортированные профили (`ielts-teacher-*.json` в `.gitignore`).

## Код
- Без сборки и зависимостей: vanilla JS. Логика плана — в `app/js/engine.js` (чистые функции) и обязательно с тестом в `tests/`.
- Контент (темы, вопросы, карточки) — `app/data/content.json`.

## Переводы
UI и документы пока на русском. PR с переводом на английский и другие языки приветствуются.
